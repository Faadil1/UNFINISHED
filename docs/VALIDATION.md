# Validation Summary

UNFINISHED distinguishes between **prototype-level causal validation**, **live Decentraland runtime proof**, and **claims that remain intentionally out of scope**.

## Live Decentraland proof

The canonical World at `unfinished.dcl.eth` has been exercised for:

- shared Supabase state loading from Decentraland;
- `LIVE CHAIN` runtime status;
- inherited condition rendering;
- `CONNECT` / `RISE` completion;
- physical route traversal before successor authoring;
- successful `HANDOFF READY` persistence;
- self-handoff refusal;
- mobile gameplay;
- mobile share/open fallback;
- recent human-chain memory;
- generation-aware visual variation;
- creation receipt / latest-state handoff presentation.

Most importantly, the backend contains a linked generation 1 → 2 → 3 chain. Generation 2 and generation 3 use different wallet author IDs, and generation 3 points directly to generation 2 through `parent_state_id`.

That is strong evidence that a second real account successfully advanced the shared chain.

## Claims discipline

### Proven / safe to claim

- native Decentraland World;
- mobile gameplay path;
- shared durable Supabase persistence at submission scale;
- parent-linked cross-user generations;
- self-handoff blocking;
- latest-state inheritance;
- visible recent human chain;
- Memory Beacon visual system;
- 2.5D web onboarding sandbox isolated from the real chain.

### Not claimed

- unique per-handoff URLs;
- arbitrary parallel chain routing;
- production-grade atomic multi-writer concurrency guarantees;
- reconnect/offline recovery guarantees;
- production moderation / griefing controls;
- large-scale production load or abuse resistance.

The submission should show verified reality, not extrapolate beyond the proof.
