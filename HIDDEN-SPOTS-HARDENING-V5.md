# UNFINISHED — Hidden Spots / Hardening V5.3.2

## Hardened in the browser prototype
1. **System replacement / Human necessity** — matched HUMAN/WORLD conditions remain available for falsification.
2. **Cosmetic authorship** — inherited `anchor/vector/reach` changes the actual completion topology.
3. **Self-completion** — same opaque prototype identity cannot resolve its own HUMAN state.
4. **Display-name authority** — names are presentation/social continuity only; authority uses opaque session identity.
5. **Stale/fork writes** — exact local CAS refuses stale state advancement.
6. **Successor problem** — completion resolves one pressure and deterministically creates the next.
7. **Retention** — creation/return receipts expose what happened after a contribution.
8. **Cold-test source leakage** — matched links are opaque and provenance/chain UI is hidden before debrief.
9. **URL leakage** — readable HUMAN/WORLD/geometry query strings are replaced by opaque state tokens for matched tests.
10. **Human residue quality** — operator HUMAN authoring requires a real alphabetic alias.
11. **Human-chain continuity** — organic/demo successors may optionally sign their contribution; the capped chain travels with the state.
12. **Anonymous participation** — naming is optional for successors; missing identity becomes `Anonymous` rather than blocking play.
13. **Note continuity** — optional short note travels with organic/demo state and is treated as presentation metadata.
14. **Demo replay staleness** — root demo uses a fresh per-page chain id so replay cannot inherit an already-advanced local demo chain.
15. **Judge vs research conflict** — demo skips research survey; cold-test mode retains it.
16. **Technical evidence overwhelming story** — judge receipt is human-readable; tokens remain operator evidence only.
17. **Mobile canvas + form split** — mobile controls overlap the world as an in-world bottom sheet and preserve more world area.
18. **Reduced motion** — motion-dependent effects preserve a reduced-motion path.

## Yellow — do not overclaim
1. **Durable shared persistence** — URL/localStorage transfer is a prototype, not a shared backend.
2. **Atomic shared concurrency** — local CAS is not server-side atomic concurrency.
3. **Authoritative Decentraland identity** — not yet bound to actual Decentraland identity.
4. **Actual Decentraland Mobile runtime** — browser mobile QA is not DCL camera/avatar/collision/performance proof.
5. **Reconnect/offline recovery** — not proven.
6. **Moderation / abuse / griefing** — successor names, notes and authored states need production moderation policy.
7. **Impossible/dead-end state recovery** — shared-world repair policy belongs after validated PDPB/build.
8. **Scale retention** — human-chain readability and receipts are prototype-level; population-scale retention remains unproven.

## Submission rule
Use honest language: V5.3.2 demonstrates the causal social primitive and the intended human continuity experience. It does not claim production infrastructure that has not been built or tested.
