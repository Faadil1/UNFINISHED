# UNFINISHED

**Leave something real for what’s next.**

UNFINISHED is an asynchronous social-play concept for the Decentraland Friendzone Mobile Buildathon. A visitor inherits an unfinished spatial condition authored by another real person, completes it into a usable route, traverses the result, then authors what the next visitor will inherit.

> **NO ONE FINISHES WHAT THEY START.**

## V5.3.2 — Final Experience Build

Live: `https://unfinished-delta.vercel.app`

Operator / matched test authoring: `https://unfinished-delta.vercel.app/?author=1`

The final experience translates the validated causal prototype into a world-first mobile journey:

**CREATE → INHERIT → COMPLETE → CONTINUE**

- architectural floating-world presentation rather than abstract prototype shapes;
- tactile press-and-hold completion and direct route traversal;
- human provenance and optional notes in judge/demo play;
- optional successor name, creating a visible chain such as `Maya → Faadil → Benita → …`;
- human-readable creation/retention receipts;
- opaque source-neutral matched links for cold tests;
- deterministic causal engine remains unchanged.

## Causal grammar
Human-authored: `anchor + vector + reach`.

Deterministically carried: `pressure + tension + engineBias`.

`CONNECT` resolves SPAN and creates HEIGHT.
`RISE` resolves HEIGHT and creates SPAN.

Names and notes make the social chain legible; they do not authorize or randomize the engine.
