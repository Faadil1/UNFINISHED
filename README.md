# UNFINISHED — Playable Co-Authorship Kill Test

Status: **PROTOTYPE / KILL TEST LIVE**, not yet PDPB/PRD.

Live mobile prototype: https://unfinished-kill-test.vercel.app

Core hypothesis: a previous real person's unfinished spatial decision can materially shape the current player's play, and the current player can leave an unfinished decision for the next person.

Rule: **NO ONE FINISHES WHAT THEY START.**

## 2×2 scope

| Prior stem | Completion | Outcome |
|---|---|---|
| ARC | CONNECT | GATEWAY |
| ARC | RISE | ARCH CLIMB |
| STEP | CONNECT | CROSSING |
| STEP | RISE | STAIR TOWER |

The prototype alternates HUMAN vs WORLD attribution and ARC vs STEP.

## Gates
1. Recognition — ARC and STEP are perceived as different inherited states.
2. Counterfactual Authorship — the same completion produces a materially different path depending on the inherited stem.
3. Human Necessity — HUMAN attribution matters more than WORLD attribution.
4. Playfulness — after reveal, the tester uses the result rather than searching for more configuration UI.

## Strong PASS signal (5–10 cold testers)
- >=4/5 can explain, unprompted, that they completed something left unfinished by another visitor.
- median Human Necessity >=4/5 on HUMAN variants.
- median Fun >=4/5.
- >=80% use the transformed route before asking for another instruction.
- testers can separately state what the previous contributor did and what they did.

## KILL/PIVOT
- described mainly as “choosing/building a shape”;
- HUMAN and WORLD feel equivalent;
- transformed topology is not used;
- ARC vs STEP feels cosmetic;
- first contributor is not remembered.

No network request is made. COPY JSON exports one test run locally.
